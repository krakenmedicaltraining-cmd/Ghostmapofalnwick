# Ghost Map of Alnwick — V9

Mobile-first interactive companion for the physical **Ghost Map of Alnwick** hunt and Edgar Thorncroft story.

## V9 features
- Ten-location hunt in story order
- Two independently verified real-world clues per case
- Harry the Innkeeper and UNKNOWN story messaging
- Incoming-call and corruption sequences
- Progressive field-kit unlocks
- Spectral Camera using location-specific apparition artwork
- Local microphone EVP recorder
- Spirit Box, EMF and environment game effects
- Persistent scrapbook via IndexedDB
- Edgar field-recording slots
- Personalised completion certificate
- Settings, accessibility controls and hidden test mode

## Required assets
Location illustrations go in `assets/locations/` using their displayed location names, Harry portraits in `assets/harry/`, ghost art in `assets/ghosts/`, Edgar audio as `audio/case01.mp3` through `audio/case10.mp3`, and the certificate background as `assets/certificate.png`.

The paranormal detector readings and apparition effects are fictional entertainment features. Microphone recordings remain local to the player's browser.
